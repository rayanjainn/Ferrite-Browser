// First launch

Three steps, then connect a model.

macOS

  1. Unzip and move Ferrite.app to Applications.
  2. Open it. macOS blocks it once, because it is not notarized.
  3. System Settings → Privacy & Security → Open Anyway. Or run xattr -dr com.apple.quarantine /Applications/Ferrite.app.

Windows

  1. Unzip the folder anywhere.
  2. Run ferrite.exe.
  3. If SmartScreen asks, choose More info → Run anyway.

Linux

  1. Extract: tar xzf ferrite-*.tar.gz.
  2. Run ./ferrite or ./install.sh.
  3. You need a graphical session with OpenGL/EGL and the libraries in README.txt.

// Or build it from source

Compile it yourself.

You need a recent Rust toolchain (the repository pins stable) and a C toolchain with cmake and pkg-config. The first build compiles the Servo engine: plan on 20 to 60 minutes and 10 GB or more.

$ git clone {{REPO}}
$ cd Ferrite-Browser
$ cargo run --release -p ferrite-shell --features ferrite-servo/servo

Without the Servo feature, the whole defense, the evaluation harness and the test suite still build and run with cargo test --workspace, with no network and no API key. Run it from source lists every recipe.
